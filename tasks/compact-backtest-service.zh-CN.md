# 简化回测服务操作

## SC-01 — 界面

正常回测页面只显示简短状态和 `服务管理` 展开入口。刷新、待恢复任务查询、停止服务、更新时间、说明和返回链接收进其中。服务异常、控制结果未知、服务已停止／未启用或发现中断任务时展开。已授权运行中的任务不视为中断任务。任务进度、取消、准备状态刷新和同一请求重试保留在原页面。

## SC-02 — 读取与控制边界

复用现有组件／组合函数和 API 契约。`canRead=true` 且当前没有已授权任务时，最多检查一项未完成任务。检查成功后，在服务启动／修订／代次／状态／授权身份改变前复用结果，也可手动查询。后台临时 503 留到既有状态轮询重试；手动失败及其他读取错误仍显示。不因检查而在可读前准备存储、启用执行、恢复任务或提交付费提取。恢复仍须明确勾选确认；控制原请求体／键、取消和实际排空规则不变。

## SC-03 — 验证与状态

**SC-01–SC-02 范围内完成。** 最终前端 71 个文件／1088 项测试通过，含 32 项服务测试；类型检查和生产构建通过。三条定向真实 Chrome 流程通过；实际四份计划结果在 1440、390、320 像素下检查，无溢出或控制写请求。原取消／重试测试保持完整。扩大浏览器检查发现的既有导航中断及准备读取失败，在隔离的修改前基线上同样复现，不归类为通过。依据和限制见 [SC-V01–SC-V04](../docs/verification/2026-10-18-compact-backtest-service.zh-CN.md)。本任务不改变计划规则、报告身份或验收门槛。
