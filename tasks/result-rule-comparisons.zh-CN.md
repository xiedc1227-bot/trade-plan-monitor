# 冻结结果规则对照

## RC-01 — 契约

连续回测结果页列出全部计划原文及紧邻前序。展开某份时加载 `GET /api/v1/backtest-runs/{run_id}/rule-changes/{source_id}`。每次返回一份完整对照，绑定运行、清单、原文及版本。按稳定规则 ID（风险分支使用 kind）比较最终冻结快照，不读取可变准备记录或重新调用 AI 解读。首份规则为 ADD；相同值为 RETAIN；变化值为 MODIFY；消失的规则为 REVOKE。旧独立版本明确标注，同时仍比较相邻快照。持仓陈述不会重置账户。

## RC-02 — 展示与边界

显示四组分类、完整前后字段、易读名称、元单位价格及股数。保留内容可以展开，无需阅读原始 JSON 理解规则。一次加载一份，不固定原文总数。读取失败明确提供重试；切换运行后取消过期响应。现有汇总大小边界及冻结报告哈希不变。本次读取不调用 AI、不回放、不发布结果、不迁移数据库。

## RC-03 — 验收

测试首份建立、保留、修改、新增、取消、保留标识的规则重排、独立版本、原文不存在、过期请求及不安全原文文本。在实际浏览器验证四份冻结计划，包括第二份取消入场、第三份保留退出、第四份修改首笔／新增第二笔／取消退出。同步更新中英文操作与验证记录。
