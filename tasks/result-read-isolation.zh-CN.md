# 已完成结果读取隔离

## RR-01 — 根因与修复

四份计划结果读取重复校验同一冻结输入，占用元数据通道的时间超过其 5 秒读取准入期限，并发的任务、数据集与重复结果请求返回 503。保留全部证据校验与历史字节，将耗时结果投影与任务、接收元数据隔离，只共享重叠的相同读取，并在同一读取快照合并输入、报告和诊断。

## RR-02 — 实施与边界

- [x] 每次结果投影只读取校验一次复制行情，保留报告绑定、完整保留事件摘要、类型化记录、诊断上限和过期处理。不增加持久结果缓存、存储投影或改写报告。
- [x] 增加一个惰性、有所有者的结果读取线程，最多一个物理调用、8 个观察者及 8 个不同进行中键。不同键等待准入最多 60 秒。元数据保留现有 8/5 秒边界。按操作、运行、来源分键，汇总响应键包含固定状态。不增加执行权限或重任务工作线程。
- [x] 仅共享进行中的相同请求，后续每次读取重新校验存储。取消观察者不取消其他观察者，也不释放物理工作。停服、错误转换和物理排空统计纳入结果所有者。

- [x] 相关后端 155 项、结果 API 25 项通过。回归覆盖投影被阻塞时任务仍可读、重复与取消观察者、后续重新读取、有界过载和排队超时、停服、审计损坏与过期证据。移除请求共享后回归失败，准确源字节已恢复。
