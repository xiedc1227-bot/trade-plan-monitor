# 回测数据自动准备

## AD-01 — 已授权行为与边界

用户已授权实施一个开始操作：检查本地证据、补齐缺失历史数据、验证并冻结数据集，然后回放已审核计划链。从界面移除 `应用到当前 URL`、`同步历史数据`、`本地验证数据集` 和 `刷新已缓存表面`。无需调用 AI。只读访问不得授权下载。保留进度、取消、同一请求安全重试和失败后的明确重试。已有冻结输入、数据集和报告必须保持不变。

## AD-02 — 实施

- [x] 服务端从已审核单份计划或组合推导范围和预热要求。增加严格绑定清单的只读数据检查；最终接收回测时重新检查并冻结执行依据。可在审核依据、账户、数据要求和截止时间完全匹配时复用已校验的结果副本，最多检查 20 个匹配输入，新提交不改写旧对象。
- [x] 开始后自动检查，仅在需要时提交现有有界、持久化的数据同步任务，等待服务端权威状态、重新检查，再提交现有回测命令。同步请求保持幂等，取消或离开页面后不得继续后续步骤。不增加第二个工作线程，不静默恢复旧任务。
- [x] 历史数据管理改为只读，说明开始回测时自动准备。保留列表筛选、分页和任务查看、取消。
