# ADR 0006：使用有界服务端处理完成混合原文复核

对应英文文件为正式版；本文为中文审阅副本。

- 状态：已接受；冻结审核兼容设计依据
- 当前范围：`SPEC-unified-plan.md` 负责新提取/审核及模拟库存；本 ADR 保留准确历史处理身份。
- 日期：2026-09-12
- 取代范围：仅修改 ADR 0005 对新服务端复核映射/证据版本的约定

## 背景

R11 v2 模拟提供商测试证明类型化来源映射及阻断，但派生三规则简写仍无法完成复核：现有持仓和提醒隔离语句不是可执行计划字段。R08 C02/C09 明确把它们放在独立持仓及产品边界。整条混合子句只映射 symbol 会丢失含义；始终未解析又会使受支持原文永久无法复核。

## 决策

采用 [SPEC-source-treatment-review](../specifications/monitoring/SPEC-source-treatment-review.zh-CN.md) 的有限契约。所有 v1/v2/v3/v4 提示词/输出 Schema 和 golden 摘要保持冻结。只扩展服务端映射为 `plan-mapping-v2`，包含 `source-processing-v1`，并使用证据域 `plan-review-evidence-v2`。模型 v4 输出仍为 v1；新保存从精确完整子句推导 v2 处理记录。已存 v1 快照继续使用既有复核路径。

处理范围仅含独立登记的持仓声明和已实现的 `alert-position-isolation-v1` 保证。通过重新推导校验精确原文区段和参数值；每条处理均要求当前快照的明确审核。不存在通用忽略/已读分类、AI 选定产品契约或库存副作用。按 E07，内容批准与实时库存就绪继续分离。

复用映射 JSON 与解决记录存储；无需数据库迁移或新增外部依赖。普通读取/复核拒绝未知版本及被篡改的处理记录。旧程序不能读取新 v2 映射；恢复应使用向前修复或兼容备份，不得删除处理记录降级。

## 备选与验收

拒绝：全部混合原文绑定 symbol；删除/改写原文；通用非交易豁免；内容批准永久 false；要求实时库存持续有效才能保留语义批准。

验收要求使用提供的逐字原文（仅 `测试股票` → `003043.SZ` 替换）、真正完成并取得 reviewId、公开 R12 激活拒绝、独立幂等库存登记、已验证的提醒/已读隔离、遗漏/夹带/篡改对抗测试、冻结提示词检查及双语证据。此前简写及 v1/v2 语义语料继续作为正确标注的历史 fixture 保留。
