# 原生所有者核算 P0 规格

## NOA-S01. 范围
仅在隔离子进程实施双语方案。保留独立权威检查、完整证据校验和物理取消/排空。覆盖与所有权未合格前，不替换生产分配器、不降低预算、不推进 P1。

## NOA-S02. 观测器
完整初始化后包装已有 Python RAW/MEM/OBJ 分配器；保留既有 arena 策略。在驱动导入前配置实际 SQLite DLL。采用有界原生记录、线程安全的指针/域记录、释放时保存的所有者及保守 realloc 重叠。报告基线未知释放、记录丢失和观测开销。逻辑域总数不是去重后的底层上界。

## NOA-S03. 实验
记录原生源码/构建/运行时身份。验证小/大对象、密集错误、实际 SQLite 查询、跨线程释放、迟配置及固定表耗尽。oracle 输出在测量进程外比较。保留既有篡改、时间、死锁、清理和排空回归。任一覆盖/所有权门槛失败就停止依赖的准入修改。

## NOA-S04. 验收
保持 64 MiB 输入、768 MiB 工作集和 2560 MiB 私有提交量。合法行预算变化前要求源码上界、arena/底层核对及有预算的结果转移。三轮诊断不是合格性能。未执行门槛如实报告；方案全部门槛通过前 P1 保持 NO_GO。
