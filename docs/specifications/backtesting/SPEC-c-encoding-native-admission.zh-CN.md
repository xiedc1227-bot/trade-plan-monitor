# 原生准入 P0 规格

## CNA-S01. 范围

按双语 CNA 提案实施隔离实验，保留全部已有文件和并行工作。不注册生产路径、不写真实数据、不提交或推送。P1 有条件推进。

## CNA-S02. 表示

试验融合规范化与保守边界累加，消除每个容器的浅副本及第二次子项遍历。保留 model_dump/round_trip、精确标量语义和全部规范字节。旧生产者作为差异对照。不能因 Python 遍历消失就删去原生分配计费。

## CNA-S03. 所有权与准入

记录已安装二进制/源码/模型指纹和明确的分配所有权矩阵。测量成功不代表证明了原生分配上界。保持 `64 MiB`、`768 MiB`、`2560 MiB`、`8` 个读者、`1` 个证明、`1` 个排队 owner、`15-second` 等待、`90-second` 资格及 `2` 次尝试。原生来源或分配边界失败时禁止减少预留和集成完整筹资预算。仍执行合法大行 SQL 准入诊断，将拒绝记录为可用性失败。

## CNA-S04. 验证与门槛

在相同冻结输入上对比原版、旧 C 生产者及融合候选，运行 `3` 轮诊断，独立于测试和内存探针。验证长 Decimal、密集对象/错误、全部 `19` 个字段、重算根后的域篡改、并发隔离/死锁、时间边界、取消和清理债务。保留独立权威检查和完整历史证明。P1 须先通过原生及可用性门槛，再完成 `10` 组 A/A、`20` 组 ABBA/BAAB、`20%` 混合收益、结果回退最多 `5%`、监控/CPU 回退最多 `10%`。未集成实验不宣称浏览器通过。
