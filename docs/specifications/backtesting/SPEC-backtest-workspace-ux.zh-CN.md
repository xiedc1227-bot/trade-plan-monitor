状态：用户于 2026-10-21 明确批准本次实施范围。基线：`2be0a8b`。[英文主文档](SPEC-backtest-workspace-ux.md)。设计：[方案](PROPOSAL-backtest-workspace-ux.zh-CN.md)。任务：[实施](../../../tasks/backtest-workspace-ux.zh-CN.md)。

## BW-C01. 范围

完成方案全部 P0，以及现有接口支持的 P1：运行查找、已验证数据集浏览、已接受任务查找、服务操作层级、紧凑审计/来源页、权益控制和受支持结果操作。定位并修复已测得的结果读取瓶颈，保持完整性校验。

现有路由与写操作语义仍为依据。全局覆盖清单、新增全量审计/日期筛选、图表与成交关联、可编辑命名、草稿复制、对比和额外导出后置。浏览不包含历史补建、删除或供应商下载。

## BW-C03. 读取契约

10 秒显示慢读取提示；30 秒结束/替换该读取并允许重试，保持旧响应保护。卸载/查询变化清理定时器并中止旧读取，不取消或提交任务。同查询刷新保留有标注的旧数据和最后成功时间；新筛选清除不匹配行。刷新失败时不能把保留数据展示为最新成功结果。

区分历史为空、目录为空、无匹配、读取失败、证据缺失与过期。服务可读取和结果可读取是不同事实，不能从当前页或证据截止时间虚构全局总数或实际完成时间。

## BW-C04. 运行与数据查找

采用紧凑页头/筛选。主要运行行包含股票、事件区间、短身份、可用结果指标、成交数、保留状态和明确结果动作，完整 ID 可展开。比例显示明确百分比单位，不以二进制浮点计算金额。缺失指标保持不可用，并在响应支持时解释原因。

运行记录提供股票代码和保留状态筛选；删除回测截止日期控件及其“更多筛选”区域。移除旧 URL 中的 `eventEndFrom`/`eventEndTo` 参数及关联游标，重置到第 1 页，运行记录页面不再发送这两个参数。现有 API 日期筛选能力保持兼容。数据集日期仍筛选目录起止边界，不表示区间重叠或完整覆盖，并使用原生日期控件。保留清空筛选和生效条件摘要。已访问游标支持上一页/首页/下一页，有限历史最多 30 条，未知前序不伪造。从结果返回时恢复 URL 筛选/页码及原行焦点。

历史行情数据明确是已验证目录，空目录不能暗示结果/计划删除，提供相关记录导航。数据集行显示股票、带标签区间和验证状态/时间，预热、全部 7 个计数、哈希、Schema 和原始阻断项可展开。已知阻断项提供可操作解释，未知代码仍可查看。

## BW-C05. 任务与服务契约

`/backtests` 内区分结果/任务。任务查询使用已有有界 `GET /api/v1/backtest-jobs`，支持状态/类型和游标，以 `jobId` 打开选定任务。展示待处理/运行中和终态，不把任务 ID 当成运行 ID。结果链接仅在完成状态且任务提供匹配非空运行 ID 时出现。读取不恢复任务、不新建任务。

展示阶段、真实单位、服务端更新时间和允许动作，未知总量不虚构百分比/预计耗时。复用取消确认、请求取消与已确认取消区分、结果未知时同请求重试。重新打开已接受的数据/运行任务，不承诺浏览器持有的准备链自动继续。停止服务放入高级操作并显式确认，修复不隐式恢复任务。

## BW-C06. 基于现有数据的结果浏览

审计事件使用紧凑行，按需展开记录内容/身份，复用已有精确原因链接。精确日期查询具备前，参考指数动作明确只是打开决策记录。

来源页优先展示生效版本选择与已有按需规则对照。账户、假设、指标、技术来源身份可展开。对照缺失/失败不能等于无变更；历史可用时间假设保持可见。

权益提供图例开关和已有最多 2,000 个展示点上的有界缩放。精确值保留在可展开原生表格。解释资金/估值限制，不推断新收益率/回撤、配对交易盈亏或时间/成交身份。保留解释为防止明细常规过期；导出只展示后端实际支持格式。

## BW-C07. 性能与完整性

在相同已完成运行上分别记录 API/响应体/浏览器与存储投影测量。现有观察包括详情 API 约 9.6/4.7 秒，带剖析存储读取约 9.3 秒；剖析开销意味着这些数值不能直接比较。

优化已证实的重复工作，不跳过校验，不缓存会变化的可用性。结果仍须反映保留/置顶修订，并拒绝损坏的制品/事件。缓存必须有界、绑定全部证据身份并在底层状态变化时失效；能够消除重复工作时优先采用单次已验证遍历。相同输入核对前后变化，如实报告剩余冷读取成本。
