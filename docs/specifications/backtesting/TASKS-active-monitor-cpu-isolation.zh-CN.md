# 活动监控 CPU 实施任务

[英文规范版本](TASKS-active-monitor-cpu-isolation.md)。[规格](SPEC-active-monitor-cpu-isolation.zh-CN.md)。

- [x] AMC-T01：建立双语一致性、范围指纹、冻结输入及声明的测量顺序。
- [x] AMC-T02：编写有界权威/指数/事件循环归因及诊断失败不影响业务的失败测试。
- [x] AMC-T03：实施 P0 观测，不改变权威、证明或物理所有权决策。
- [x] AMC-T04：运行固定单进程可行性、完整相等/篡改/取消检查及独立内存观察，保留全部尝试。
- [x] AMC-T05：测量观测开销及真实请求时间线，对齐慢请求并区分实际重叠。
- [x] AMC-T06：依据原门槛决定 P1；仅在前置条件全部通过后实施，否则记录不推进。
- [x] AMC-T07：完成相关后端、变异、浏览器、类型、规范及双语验证。
- [x] AMC-T08：发布双语报告及脱敏证据，包含前后对比、限制及并行工作保留情况。
