# 有界校验传输规格

[英文规范版](SPEC-bounded-validation-transport.md)。[提案](PROPOSAL-bounded-validation-transport.zh-CN.md)。获准实施的基线：`f430c96`。

## BVT-S01. 范围

P0 是位于 `scripts/experiments` 的隔离、可复现 Windows-spawn 实验，配套针对性测试和冻结只读数据。生产模块、数据库、服务及配置保持不变。保留已有提案/证据和并行 AI 提取/日库存改动。本阶段不提交推送。P1 以全部门槛通过为条件，包括明确的生产全局所有权/计费契约。

## BVT-S02. 协议与纯核心

使用私有双向管道、单个物理工作器和单个未消费输入帧，上限 1 MiB。使用显式标量标签表示空值、bool、有符号整数、UTF-8 文本及字节；不支持的标量或超大行在提交前选择整次证明线程回退。保留原始 JSON 字节、类型、缺失载荷和顺序。不使用可执行 pickle 协议。有界消息绑定版本、工作器代际、任务、序号、条数及长度，最终条数及有序摘要必须一致。意外 EOF、尾随字节和串消息均失败关闭。只调用一次未改动的 `_latest_index_records`，保留全局排序及全部 `_market_index_from_row` 校验。响应承载有界 JSON 记录；失败只携带固定代码。接收完成与物理清理是不同事件。

## BVT-S03. 预算

输入/副本总准入保持 <=64 MiB。在传输分配前预留 16 MiB，并计入父进程原始保留量和外部同时存活的输入租约；原型必须显式报告外部租约，单个冻结调用者也须报告其为零。原始分块最大 2 MiB，编码块最大 1 MiB。预留覆盖编码/接收/内核副本、子进程重叠分块、解码源文本、有界输出/控制和规划开销。如不能证明保守上界，记录门槛失败，不能宣称安全。超大行、不支持的类型、输出边界或总余额不足时，在提交前整体回退全量线程校验。绝不序列化全部输入。租约保持到实际清理结束；取消不会返还租约。

父子进程同时刻工作集及私有提交量与输入计费分开测量。已解析模型、解释器基线和分配器保留需要在 P1 前设定绝对进程内存门槛。P0 必须披露所有未证明的分配上界，包括并发 SQL/比对批次，不能用单调用者结果认证生产并发。

固定采样前，冒烟运行因初始 0.5 MiB 输出预留太小而选择线程回退，保留该记录。最终配置在不变总额内允许 1 MiB 输出，并按 `8 * wire + 2 * raw + 2 * text + 2 * OUTPUT + MiB <= RESERVE` 拆分块；每块解码源文本上限为 1 MiB。这是需要运行时佐证的保守原型计费范围，不代表已证明所有 Python/内核分配大小。在 300 次观测前冻结此配置。

## BVT-S04. 所有权

保留独立权威前后检查、事务、时钟、激活检查、2 次尝试、全历史完整性、精确在途比对、8 个读取、1 个校验器和 1 个排队所有者。观察者独立取消；物理输入供给、结果消费和清理由所有者继续完成。提交后不回退，不重复校验。协议/子进程执行失败则隔离代际。清理失败保留租约。正常停止等待子进程退出；应急拆除丢弃通道，确认进程退出后才释放。采用独立于现有请求截止时间的 30 秒原型监督上限，不作为新的生产超时。确定性测试门控不计入性能测量。

## BVT-S05. 固定实验及门槛

使用已有冻结监控/结果输入及匹配的不可变结果所有权。对单独监控、单独结果和混合负载，分别固定 10 组 A/A 对照加 20 组交替 ABBA/BAAB：每变体 40 次测量，每负载另有 20 次对照，共 300 次。混合结果在物理提交后启动。保留全部尝试/回退/失败和完整输出哈希。冷启动及每变体 3 次新进程内存观测另计。记录父/子 CPU、完整完成时间、IPC、精确输入条数及物理排空。测量前固定 1 MiB 帧，不替换不利样本。

要求混合结果中位数改善 >=20%，单独结果退化 <=5%，监控中位数及父子总 CPU 退化 <=10%，完整输出相等、输入副本有界、生命周期安全。P1 前冻结绝对进程内存限制及生产全局租约所有权。任何前置条件失败或未证明，都判定 P1 暂缓。若推进 P1，先补充双语契约，再执行此前提出的每变体 100 次真实所有者验收和浏览器检查；每变体成功观测不足 >=100 次时不宣称 p95 改善。

## BVT-S06. 验证

实现前先写失败的编码/准入测试。覆盖空/单条/分块边界/大记录/不支持输入、字节限制、精确往返、截断/重复/乱序/串帧、最终条数/摘要错误、过期结果、旧的/未选中证据篡改及 canonical/head/provider 绑定。验证工作前/中/后取消、跟随者存活、重复取消、崩溃/卡死、通信阻塞、子进程清理失败和存储屏障回归。对完整性、权威、流完成和提前释放执行变异检查。运行相关既有所有权/完整性测试和限定范围 lint。发布双语报告，披露全部限制及实测对比；仅 P0 实验不改变浏览器行为，不宣称生产提速。
