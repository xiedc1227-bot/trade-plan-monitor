- [x] RLT-T01：补齐双语规格/任务。验收：ID、数字、边界及命令等价。验证：修改源码前检查对应文件、链接与技术标记。
- [x] RLT-T02：增加有界显式启用追踪与 HTTP 关联。验收：禁用/溢出/失败不影响业务，固定字段、有界存储、明确响应残余。验证：先失败测试，再聚焦通过。
- [x] RLT-T03：在线程和共享观察者之间传递物理所有权，标注既有校验边界。验收：同 key 调用者引用同一物理追踪，取消不能抹去或释放进行中工作，每个权威/证据检查仍被调用。验证：跨线程、失败、取消和排空测试及既有回归。
- [x] RLT-T04：采集真实所有者成功基线/实施后场景和浏览器时间线，单独测量观测开销。验收：满足 RLT-S04 数量/上限，或明确失败/未复现范围；不把合成延迟算作真实延迟。验证：原始样本、追踪核对、无控制台错误及只读浏览器交互。
- [x] RLT-T05：依据归因结果和原有门槛决定 P1。验收：只保留完整验证的收益，否则记录暂缓。发布双语对比/测试报告及局限，检查最终差异。验证：完整性/保留/变异/所有权套件及文档等价。
