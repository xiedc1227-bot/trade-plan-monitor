# 首次结果页监控启动

## IMS01. 范围与契约
仅首次进入 `backtest-run-detail` 时，将同一应用监控延后至首次结果成功或失败，最长计时器为 `5000 ms`。其他路由及已运行监控保持原行为。切换路由释放启动门；卸载取消计时器并阻止迟到启动。结果身份无效时不发请求并释放启动门。待连接状态如实展示。应用壳拥有启动职责；结果视图通过类型化注入报告结束。不修改后端、原生核算、证据、权威、取消及排空。保留无关 AI 提取、日库存及 README 工作。

## IMS02. 验收与停止
同一数据、排空起点下固定执行 `20` 对交替基线/候选浏览器对照。就绪中位数须同时改善 `20%` 和 `1.0 s`。结果单读及并发 API 耗时和实测总 CPU 回退不超过 `10%`；错误/拒绝/超时不增加。不声明 p95。正确性/边界退化或固定门槛未通过则拒绝，不扩展范围、不追加样本直至通过。计时器限制主动延后；事件循环挂起时不能保证墙钟执行时间。

同一结果的查询参数规范化不释放启动门；不同路径会释放。
