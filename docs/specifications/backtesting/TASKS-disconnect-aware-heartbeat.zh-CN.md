# 感知断连的心跳实施任务

[英文原版](TASKS-disconnect-aware-heartbeat.md)。[规格](SPEC-disconnect-aware-heartbeat.zh-CN.md)。用户授权执行 P0，2026-10-22；排除并行 AI 提取工作。

- [x] DHA-T01：恢复双语规格/任务一致。验收：实施前 ID、数字、标记、命令与边界等价。验证本地链接和对应文档检查。
- [x] DHA-T02：源码修改前采集真实所有者成功基线。验收：只读历史、真实协议/周期、关闭及已连接对照；保留失败和诊断限制。验证脱敏浏览器/服务端关联。
- [x] DHA-T03：增加当前源码失败的断连/准入测试。验收：证明无用健康读取及取消缺失；覆盖终止/截止时间/发布竞争。验证有意义的失败断言。
- [x] DHA-T04：实现接收/发送监督与准入守卫。验收：连接局部终止状态、子任务有界、终止后无健康准入、等待清理且协议不变。验证聚焦测试通过及默认禁用追踪。
- [x] DHA-T05：验证所有权、证明和存储竞争。验收：存活跟随者仍经校验，废弃工作物理排空，清理失败保留暂停，停止态临时健康清理仍被等待。验证回归与变异探针。
- [x] DHA-T06：采集真实所有者浏览器/改后数据与受控开销。验收：DHA-S05 样本数或明确缺失范围；数据/周期相同，保留全部失败，不把合成延迟当真实提速。验证请求/追踪关联及只读交互。
- [x] DHA-T07：发布双语报告并最终审查。验收：对比和限制、测试、保留的权威/完整性主体与排除的改动。验证规范/类型/浏览器/文档检查。原实施阶段不提交/推送；后续用户指令授权审查并按范围提交/推送，排除并行 AI 提取及日库存改动。
