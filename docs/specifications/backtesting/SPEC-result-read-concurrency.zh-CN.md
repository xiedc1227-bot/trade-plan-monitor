# 已验证结果读取性能契约

状态：用户于 2026-10-21 授权实施。基线：`cd5113b`。设计：[方案](PROPOSAL-result-read-concurrency.zh-CN.md)。[English 原本](SPEC-result-read-concurrency.md)。任务：[实施清单](../../../tasks/result-read-concurrency.zh-CN.md)。

## RRC-S01. 范围与边界

交付 P0 有界冻结文件读取与限定监控导航刷新。重新测量后再推进 P1 监控批量读取及等价规范化优化。仅当剩余测量证明其并发/生命周期复杂度值得时，才新增有界监控在途共享。保留双语方案和全部已有改动。不新增 schema/API 迁移、供应商下载、证据删除、金融计算变更、超时延长或线程池扩容。

## RRC-S02. 责任与契约

| 责任方 | 职责 |
|---|---|
| `LoopInputStore._read` | 分块读取最多 `_MAX_OBJECT_BYTES + 1` 字节，每块不超过 65,536 字节，保留目录/链接/大小/分域/哈希检查及后续类型/规范校验。 |
| `runtime-status/App.vue` | 识别导航：回测共用一个页面域，其他已解析路由保留原有完整路径身份；初始路由解析不额外刷新。 |
| `createRuntimeMonitor.navigation` | 有意义的页面域变化时，使过时请求/协议和当前可操作展示失效；新鲜快照恢复已验证展示。 |
| `ProjectionRepository.list_latest_market_index_snapshots` | 批量加载历史 head/payload，校验全部候选并保留 `snapshot_rank` 与缺失 payload 失败行为。 |
| `market_index/canonical.py` | 若测量证明有收益，高效处理精确基础值，不能改变 Decimal、enum/子类、时区、浮点拒绝或规范字节。 |
| 已有结果线程与监控读取服务 | 保留物理所有权、有界准入、取消隔离、authority 检查及 revision/可用性一致性。 |

## RRC-S03. 冻结读取验收

`_MAX_OBJECT_BYTES`、全部哈希域与 `reportHash` 不变。完整读取到 EOF 或原有最大值加一个字节停止；短读取不能被误判为 EOF。不引入跨请求已验证文件缓存。保留文件/目录所有权、符号链接/junction 拒绝、缺失/超限拒绝、类型解码、规范相等、计划/账户/数据集/输入/报告绑定及审计封套/事件集合检查。等长/同时间戳篡改后重新读取仍须失败。

## RRC-S04. 导航验收

回测列表/结果/新建/数据/任务/筛选/分页/页签切换，不能仅因 URL 变化新增监控刷新。初次启动仍读取权威快照。已解析监控路由变化、重返监控、generation/sequence 不匹配、过期、可见性恢复、重连及协议不匹配仍保留新鲜读取。有意义的导航刷新前撤销当前展示，不能从旧快照启用操作。命令预检不变。浏览不触发提交/恢复任务或行情下载。

## RRC-S05. P1 测量门槛

P0 后分别记录存储投影、HTTP 和浏览器请求数。参考样本的监控投影仍超过 1 秒，或仍为每个历史 head 查询一次时，推进历史批量读取。校验全部候选，包括未选中的损坏历史证据。使用左连接/等价缺失行检查、有界分页和相同的已验证排序，不能改成最大 revision 或信任未经检查的 SQL 排序。每次读取的校验不缓存，保留全部行/payload 身份检查。精确基础值规范化优化须验证字节/哈希相等、浮点/子类/Decimal/时间边界，并证明收益超出波动。

仅当前述优化后，重复等价物理工作仍显著且有界 authority/数据边界设计得到证明时，才推进监控共享。否则以测量记录后置原因。长效缓存/进程隔离不属于本轮交付。

## RRC-S06. 完整性与并发门槛

验证文件损坏/缺失/超限/截断/增长/替换、符号链接/junction 拒绝、错误分域/哈希、非规范 payload、异属身份和事件集合损坏。测试保留/过期/置顶证据、新鲜可变 revision 及无缓存回退。样例使用隔离存储。检查结果共享读取、不同运行排队、观察者取消、背压和关闭时物理排空；监控 generation/协议/心跳测试须继续通过。

## RRC-S07. 测量门槛

使用相同的 39 日 / 2,961 事件已完成运行。交替暖读取原始/候选路径，对比完整响应和身份；分析工具及冷读取开销另行标明。P0 样本目标：已验证投影中位数不超过 2.5 秒，且至少改善 30%。临时分配、CPU 与 SQL 分开记录。浏览器覆盖初始规范化、列表 → 结果 → 来源 → 概览、筛选/分页、前进后退及重返监控；断言业务写入和页面异常为零。不能用少量本地样本声称 p95 或通用 SLA。
