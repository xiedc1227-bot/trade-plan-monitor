## NBL-T02. 证明嵌套域核算

依赖：NBL-T01。范围：中等；`scripts/experiments/owner_observer.c`、`tests/native/test_owner_ledger.c` 和隔离的原生底层分配参考夹具。

验收：

- [ ] 已知回退别名只收取一个底层块，独立嵌套元数据和真实副本仍分别收费。
- [ ] 跨线程释放和地址复用保持原所有者/代际，上界包含操作栈与所有核算结构。
- [ ] 独立参考能够发现重复/遗漏的底层收费，不能只比较同一账本的两种聚合结果。

验证：确定性原生测试及去重/代际变异对照，记录新的二进制/源码哈希和内存开销。表、深度或 ID 耗尽时，观测无效但委托语义不变。此检查点通过只允许开展启动与生命周期实验，不允许缩减准入预留。

## NBL-T03. 验证早期启动分配来源

依赖：NBL-T02。范围：中等；隔离启动器、构建辅助程序和探针文件。

验收：

- [ ] 不启用观测的启动器保持完整输出和配置；预初始化后对照及兼容的预初始化前候选在整个启动期间保持已验证的钩子。
- [ ] 来源区分已知的更早分配、已知的更晚分配和未解决分配；阶段切换保留未释放存储及原所有者。
- [ ] 清点启动/默认/直接分配路径，记录源码支持的总量边界或明确未通过的门槛，不能把所有未知释放改名为基线。

验证：冷/热启动、兼容/不兼容的分配器设置、钩子被覆盖的负对照、早分配晚释放、延迟跨线程释放和 realloc。逐阶段比较分配器身份，记录构建可复现性和输出等价性。不替换运行时或环境策略。

## NBL-T04. 核算共享 arena 与释放完成

依赖：NBL-T03。范围：中等；观测器、原生生命周期夹具和探针报告。若需要运行时源码插桩，在启动这一独立阶段前明确其构建/等价验证范围。

验收：

- [ ] arena 登记和逻辑占用对账不重复收费，覆盖元数据、空闲空间及共享保留容量。
- [ ] free 阻塞时保留旧代际收费，允许新分配复用地址；未确认的原生释放保留为债务。
- [ ] 在有依据的边界观测原生释放成功/失败，否则明确保持未通过；转入池必须有预算。

验证：共享所有者、最后逻辑释放、预热复用、arena/地址复用、回调阻塞和释放失败屏障。核对观测器/池/进程类别，不能通过两个测量数值相减虚构上界。

## NBL-T05. 证明待完成分配与 realloc 上界

依赖：NBL-T04。范围：中等；观测器和原生操作夹具。

验收：

- [ ] 待完成 malloc/calloc/arena/realloc 记录在委托前保留旧存储并覆盖目标/临时空间，不重复预留嵌套调用。
- [ ] 失败、原地结果、移动、零大小和空指针保持底层契约与原所有者，实际分配原子替换预留。
- [ ] 钩子不等待应用准入，也不跨分配调用持锁；元数据耗尽保持保守的失败报告。

验证：屏障控制的中间快照、嵌套 realloc、小/大对象转换、多线程地址复用、分配失败、操作阻塞时取消及最终排空。提前退款或遗漏目标待分配量的变异必须失败。实际分配器/CRT 临时空间仍需源码支持，仅模拟器成功不能通过该门槛。
