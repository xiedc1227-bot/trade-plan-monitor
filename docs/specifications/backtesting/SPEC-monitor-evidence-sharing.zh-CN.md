# 有界监控证据共享规格

状态：2026-10-21 已授权。基线 `4c71bcc`。设计：[方案](PROPOSAL-monitor-evidence-sharing.zh-CN.md)。[英文规范版](SPEC-monitor-evidence-sharing.md)。任务：[实施](../../../tasks/monitor-evidence-sharing.zh-CN.md)。

## MSH-S01. 范围与顺序

保留已有方案/证据和全部改动。先测真实 HTTP/心跳重叠，再实现有界在途指数证据校验共享。不共享整个响应、健康观测、资格、权威状态或已完成校验结果。不改 API/schema、不触发行情命令、不清理真实证据、不改变保留规则、不延长超时、不增加 CPU 线程池。仅在确认回测活动任务为零且物理排空后，允许以相同配置重启本地服务。没有新请求时不提交/推送。

## MSH-S02. 接口与所有权

`ProjectionRepository.list_latest_market_index_snapshots` 保留独立流式行为，接收显式注入的监控专属校验器。提取完整不可变原始 head/payload 值和纯校验/排名函数，复用既有类型/规范化/哈希/provider/head 检查。`RuntimeStatusReadService` 拥有共享注册表及全部物理读取生命周期。`MonitorWebComposition.stop` 先关闭准入并排空读取，再销毁运行时数据库。session/ORM 实体不跨调用方/线程边界。

成功完成物理关闭后，为兼容既有行为，已持有的门面仍可通过一个新的短生命周期读取作用域提供 `get_health`；该作用域仅接受 `STOPPED` 权威状态，执行全新的完整校验，并在 `finally` 中排空。原读取所有者保持关闭，不重新开放 dashboard 准入。关闭失败时不能启用该诊断作用域。

运行时自动清理同样在实际 WAL 检查点与数据库关闭回调处执行读取排空。按代际设置的存储暂停在两个操作之间拒绝新读，超时/错误后保持暂停；关闭成功仅释放该代际的暂停。存储恢复不能重新开放组合服务的永久关闭准入，也不能解除其他代际的暂停。

## MSH-S03. 独立读取契约

每个调用方保留所属循环的权威前置捕获、自身观测时间、新鲜独占显式 BEGIN 快照、计划/库存/风险/日历/证明求值、激活身份重读和全部权威后置比较。每个调用方最多两次尝试。未知权威仍为不可用。现有 90 秒过期、日期/目标边界、progress 状态、健康年龄校验、命令预检和每个 WebSocket 的已投递游标/周期/重放不变。

## MSH-S04. 加入与证据完整性

使用左连接与 128 行获取批次，按确定 head 键顺序读取请求范围的全部历史候选。只有每个原始字段/类型、JSON 字节、缺失 payload 标记、范围和候选总数均与进行中的不可变输入相同时才共享。摘要相同绝不足够。保留未选中历史证据校验和原有已验证 `snapshot_rank`。已完成/错误 future 不能服务新调用方，即使尚未清理注册表。比较期间完成必须重新校验。不匹配/预算回退必须校验调用方完整快照，包含已消费前缀；必要时在同一事务重新扫描。不使用缓存回退。

原始内容比对读取 SQL 标量列，不使用绑定会话的实体。开始 CPU 校验前，在原请求等待期限和准入上限内，先完成已经等候输入收集的请求比对。这个输入确认阶段不延长已完成证明的存活时间。校验期间新到达的请求仍遵守相同的完成边界，不通过摘要跳过比对。

## MSH-S05. 边界、取消与关闭

限制：1 个活动物理指数校验；至多 1 个排队的不同内容 owner；至多 8 个已拥有的监控读取，包含观察者已取消但物理工作尚存的读取；全部任务合计保留 64 MiB 原始输入并计入对象开销。比较流式执行，不为每个跟随者保留完整副本。预算紧张时回退有界流式校验或既有 `SERVICE_UNAVAILABLE`。不使用无界队列或刷新等待期限。跟随者不能申请领导者的物理校验许可。观察者取消不能取消其他读取、移除任务或在物理完成前释放字节。观察全部异常。拒绝新读、撤销可操作权威、排空全部组装/身份读取和 session，再允许销毁数据库。关闭超时保留所有权并报告失败。



## MSH-S06. 测量契约

捕获逻辑读取来源/开始/结束及物理组装/指数校验开始/结束/候选数、CPU、命中/未命中和拥有的工作，不记录证据正文或凭据。生产 HTTP/心跳重叠与受控实验分开报告。真实重叠定义分母与窗口，覆盖单页、多页和结果并发路径。实时发布不适合跨轮字面相等比较：受控对比使用冻结只读副本、显式夹具权威与时钟，并标明限制。至少 10 轮交替基线/候选，覆盖 2/8 次监控读取加一次结果：CPU 中位数目标下降至少 25%；单监控墙钟回退不超过 10%。未达标必须报告，不弱化校验。还要测量服务/循环响应、等待与内存。不从该样本宣称 p95。

## MSH-S07. 安全验收

共享前证明完整输出/哈希/错误/排名等价。覆盖成功读取后篡改、同大小/时间、非规范 JSON、domain/hash/formula/provider/head 身份变化、缺失/删除/未选中证据、强制摘要碰撞与完成竞态。覆盖独立权威/配置/generation/激活变化、STALLED/STOPPING、owner 不可读、库存/风险/日历/证明变化、90 秒/日期/目标/时钟边界、相同/不同范围、领导者/跟随者/全部观察者取消、背压/字节预算和持有线程时关闭。既有结果审计/事件集合/pin/保留与监控协议/心跳测试仍必需。浏览器验证断言无业务写入/页面异常，并保留结果页与返回监控行为。

## MSH-S08. 交付

记录双语验证与可携带前后观测、实际重叠率、实测限制及测试结果。运行定向/完整相关后端测试、修改 Python 静态检查、前端单元/类型/构建和浏览器路径。保留全部真实历史证据；破坏性夹具使用隔离存储。用户实施授权优先于通用技能的审批暂停要求。
