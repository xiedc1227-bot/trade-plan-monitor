## MR01 — 目标与依赖

为联动普通BUY提供原文定义的大盘状态。复用 `market_index/identity.py`、`models.py`、`formulas.py`、`snapshots.py` 和已准入日线／日历流程。状态判断放在决策领域，不进入共用供应商事实或信息性指数展示。依赖既有指数身份／数据，为 `relative-strength` 和 `confirmation-selection` 提供不可变证据。

## MR02 — 身份与日线证据

使用已核验个股板块与现有服务端映射：SSE_MAIN → `000001.SH`；SZSE_MAIN → `399001.SZ`；CHINEXT → `399006.SZ`；STAR_MARKET → `000688.SH`；BSE → `899050.BJ`。不得替换成行业指数、`399107.SZ` 或供应商的其他工具。提取组合、审核、启用和回放准入均校验映射。范围不可用时保持阻断；能解析代码不等于已认证。

定义D为求值截止时间之前准确的最近已结束交易所交易日，不是最后到达的数据所属日。要求正式D日收盘及截至D的连续计划指数交易日历史，所有使用的修订均已在截止时间前可用。完整状态计算至少需要60个观测。盘中未完成K线、以D-1替代、合成填充、不同供应商片段拼接和未来修订均不合格。每个结果附带来源／供应商基准和公式身份。

## MR03 — 精确状态计算

I为D日收盘；M20、M60为截至D的收盘简单均线；M20_5为D之前五个交易所交易日的MA20；L20为D之前紧邻20个交易日的日内最低价最小值，不含D。使用精确Decimal比较，不按展示精度取整。新增带版本的滚动最低值事实，不改变旧事实／哈希定义。

按顺序判断：

1. `BROKEN`：`I < L20 AND I < M60`。
2. `WEAK`：已明确排除BROKEN，且 `I < M20 AND M20 < M20_5`。
3. `NORMAL_TRANSITION`：必要证据完整且前两种更高状态均不成立。
4. `UNKNOWN`：必要证据不可用，或不能排除更高优先级状态。

相等不满足严格小于。无关操作数缺失不必推翻已确定的决定性结果，但完整状态视图须列出全部缺失事实。UNKNOWN不等于NORMAL_TRANSITION。状态是计划绑定的研究政策，不是通用大盘观点。

## MR04 — 输出与集成

`MarketRegimeEvidence` 记录 `regime`、`decision_session`、`evidence_cutoff`、`reference_market`、I／M20／M60／M20_5／L20、各谓词结果、`source_hashes`、`formula_version` 与原因码。缺失数值为null，不为零。保留实际使用的准确证据集，区分数据时间与可用时间。

只采集所需指数证据；同指数／截止时间的多个股票复用不可变快照；提交前重新核对计划／审核／启用身份。指数缺失仅影响依赖它的规则。只读概览不采集数据、不赋予决策权限。P0不提高正常轮询频率、不增加第二个工作者。
