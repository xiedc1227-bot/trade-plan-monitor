## RS01 — 目标与依赖

计算提示词中准确的个股相对板块指数强弱条件，并展示可核对算术。依赖 `market-regime` 身份／截止时间证据及已准入个股日线。既有指数RETURN事实只有日期、可用时间和公式语义匹配时才可复用。相对强势不是RSI指标，也不是任意基准排名。

## RS02 — 窗口与比较

对n属于{5, 20}，计算 `stock_return_n = stock_close[D] / stock_close[D-n] - 1` 和 `index_return_n = index_close[D] / index_close[D-n] - 1`。D-n按已核验对齐日历的交易所交易日计数，不是自然日或第n个可用个股K线。两种收益计算要求完整对齐的21交易日个股／指数历史；个股MA20使用最近20个完整个股收盘。

个股价格使用单一冻结、已准入且与当前报价可比的QFQ序列；指数使用原始点位。不得混用个股复权版本、同一序列内的供应商，或用后来的复权知识改写早期回测。两个序列的来源差异须可见且通过现有可比性规则准入，不得静默拼接。

`STRONG`要求ALL成立：5交易日个股收益严格高于指数；20交易日个股收益严格高于指数；D日个股收盘大于等于当日MA20。收益相等不算跑赢；收盘等于MA20算通过。比较精确Decimal，不比较取整后的百分比。

## RS03 — 未知、输出与权限

返回 `STRONG`、`NOT_STRONG` 或 `UNKNOWN`，附带全部三个谓词结果。某项明确为假时，即便另一项未知仍为NOT_STRONG；否则任一缺项为UNKNOWN。缺日、停牌且没有合格观测、零／无效分母、复权基准不可用或端点不一致均不得编造。不得沿用旧收盘填充，不得缩短替代窗口。

`RelativeStrengthEvidence` 包含端点日期／价格、两个窗口各自双方收益、收益差、个股收盘／MA20、逐项结果、来源／基准／公式哈希、截止时间与原因。UNKNOWN不授予豁免。STRONG本身不授权买入、不覆盖技术风险；P0例外路径保持阻断。
