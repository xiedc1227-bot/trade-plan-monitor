# 规格：extraction-v12-acceptance

状态：已批准实施 — 2026-10-27。属于 [plan-monitor-assurance](SPEC-plan-monitor-assurance.zh-CN.md)，依赖 [source-condition-coverage](SPEC-source-condition-coverage.zh-CN.md)。本文不调用AI服务。[英文规范版](SPEC-extraction-v12-acceptance.md)。

## EVA-S01 — 目的与证据类别

评估准确当前提取器能否从完整交易原文生成完整、忠实且可审核的监控候选。预构造响应被schema接受、运行／回放测试通过，均不能推导提取准确率。

证据分别报告：`SYNTHETIC_TRANSPORT`（mock／内存Provider）、`RECORDED_RESPONSE_REPLAY`、`REAL_PROVIDER_EXTRACTION`、`REAL_INSTALLATION_READINESS`。测试名即使叫“真实提取”，只要使用预构造 `RawAIResponse`，仍属于传输／契约证据。已有v9纯提醒观察仅作历史参考，不是当前v12完整计划验收，也不能计算总体成功率。

## EVA-S02 — 冻结语料与独立真值

调用供应商前冻结12例。清单拥有用例标识、来源分类、原始／脱敏原文哈希、准确原文及A/B边界、语言、适用前序、提示版本／哈希、预期计划类型、预期 `PASS_FOR_HUMAN_REVIEW` 或 `BLOCKED`、必需原子义务／关系、允许产品默认值、合法范围排除、预期人工步骤及逐例资源配置。原始文件不改；批准外发前脱敏凭据／账户标识，不能删除策略条款或改阈值；本地保留脱敏记录，提交证据不含秘密。

至少4例来自用户原始来源，整体至少4例自然语言，二者可重合；至少一份原始案例须是预期通过的完整受支持交易计划。区分 `ORIGINAL_NATURAL_LANGUAGE`、`CONSTRUCTED_NATURAL_LANGUAGE`、`FIELD_FORMAT_A`，分别报告。若现有原文只有提醒或不支持计划，先准备其余样本，再提交具体原文／真值问题由用户决定，不能将合成或字段式案例改称真实交易原文。

真值独立于提取输出和 `source_mapping(draft)` 制作。冻结前独立复核原子跨度、极性、关系图、周期、窗口、数量、权限、阻断及来源边界；提取供应商不能担任自己的裁判。真实原文意图有歧义时先由用户决定，再运行该例，不以模型投票当真值。看到响应后改真值须生成新清单版本并保留早期结果，不能静默换例或把失败改成预期。

## EVA-S03 — 必需12例矩阵

| ID | 必需内容 | 预期结果／独立判据 |
| --- | --- | --- |
| PMA-X01 | Schema5纯价格／技术观察提醒，明确无普通或清仓规则 | 仅提醒可审核，不编造BUY/SELL，不要求库存／预算 |
| PMA-X02 | Schema5买卖及技术风险，混合ALL/ANY、日线和独立五分钟分支、明确日期 | 准确关系图、方向、范围、周期／offset、数量、有效期，保留风险／提醒区别 |
| PMA-X03 | Schema6按板块选指数、四种大盘状态、对齐5/20日强势及S0/S1/S2 | 来源政策完整，保留固定Q0意图，不推断例外许可 |
| PMA-X04 | Schema7明确允许两条例外 | 最小量条件准确，Qe另行人工输入；计划许可不变成逐次批准或默认Qe |
| PMA-X05 | Schema8 ATR14/收盘价连续档位及PREVIEW_ONLY费用 | 档位／基数／单位准确，先Q0后大盘因子，预览不变门槛 |
| PMA-X06 | Schema8 REQUIRED费用，明确费用、阈值、目标／风险及独立依据 | 准确费用／阈值／证据，不编默认费率或重复计算同一证据维度 |
| PMA-X07 | Schema9 OPEN_COST_CAP与CAPITAL_ONLY，明确适用买入费用，含economics NONE | 不编max_qty／现金／开仓成本，保留持仓成本口径与整笔约束 |
| PMA-X08 | Schema9 MARKET_VALUE_CAP与QUANTITY_AND_CAPITAL | 全持仓估值与股数上限准确，不新增历史成本前提或金额推算数量 |
| PMA-X09 | A/B、历史／账户／背景与前向指令混合，含否定、例外和到期 | 仅排除获证明背景，保留前向余段／关系；强制条件从A移到B须报分区冲突，不得遗漏或未经授权执行B |
| PMA-X10 | 强制换手率>3%或另一明确不支持前提；另做遗漏／背景标签变异，含同句部分映射 | 不支持义务明确阻断，不可背景豁免或以部分关系图通过 |
| PMA-X11 | 必需参数缺失、周期／窗口冲突或金额含义模糊 | 精确阻断可见，保留不完整候选，不推参、不降旧schema |
| PMA-X12 | 绑定冻结已审核前序的后续更新 | 保留未改义务／权限，改动准确，旧来源／审核绑定失效 |

X01–X09／X12使用完整原文作声明受支持的正向用例，X10／X11预先定义为阻断用例。变异属于额外离线判据，不暗增真实调用。语料覆盖中英文、原始／规范换行、紧凑及自然表述，不声称自然语言难度相同。

## EVA-S04 — 版本、调用与外部授权

基线是准确 `plan-extract-v12` 指令／模板／输出schema契约，固定契约哈希、逐例完整组装提示SHA-256、供应商／模型标识、无秘密配置、输入／输出限制及服务端覆盖规则版本。原文／用例／前序载荷不同，本来就会产生不同组装哈希，不因此改变指令版本。覆盖防护变化独立记录，不把修改的指令／模板／schema继续称v12。若确需新提示／输出版本，在T01／T15确定下一个自有版本，分别报告基线及实际部署候选。

仅在 PMA-D05 获批且用户明确要求实施后：12例各跑2次，保留全部24个计划基线结果。指令／模板／schema字节仍为v12时，不为凑预算再跑第二套；这些契约字节变化时，另做12×2候选套，两套物理供应商尝试总计最多48。关闭所有自动重试，包括SDK／传输重试；已发送的超时、供应商错误及不完整响应计入次数。本地预检拒绝使该计划用例失败，但不伪称已调用。禁止暗选最好结果或替掉失败。超预算、换服务／裁判，或预算外进一步改提示须批准。

发送前在活动共用账中原子预占次数，并发命令／进程重启不能重置或超用48上限。崩溃、超时及是否送达不明均不退回已预占发送；只有能证明零I/O的本地预检不算物理尝试。计划运行、已预占发送及已收响应数分别记录。

使用既有配置的提取服务，不新增账号或挑模型。冻结清单记录当前资源／准入设置，包括适用时原有50000字符默认输入预算；不得为过验收截原文、删绑定、提高限额或改正向预期。完整计划不能在声明配置内装入或完成时，记录能力／资源失败，将拟议限额／费用变化提交审核。如实记录取消／超时；传输超时不证明供应商未收到请求。

全部响应及评分进入独立验收目录／存储。提取调用不保存／审核／启用真实计划，不改库存／预算、不迁移、不获取行情、不发通知。只提交批准的脱敏证据，不提交供应商密钥、完整敏感配置或未经批准原始材料。

## EVA-S05 — 评分与签收

每个计划运行记录原始响应／协议结果、准确版本／哈希、结束原因、物理次数、耗时及可用usage，usage不可用为null。保留原响应与失败诊断，任何修复前独立评分：

- 强制原子召回及关系正确性：漏项、错误AND/OR、否定、日期、单位、周期／offset、数量、权限或机会均为语义失败，即使解析／审核成功。
- 不支持／模糊案例：预期精确阻断是否出现并阻止新审核／启用，有效不完整候选是否保留。
- 凭空新增：登记产品默认外的未要求条件、价格、数量、费用、批准、库存／预算成本或新权限均为失败。
- 完整受支持正向用例：是否无需人工修正即可进入审核；无根据阻断记为误阻断，不改称安全成功。
- 分开报告解析／供应商／截断失败、正确阻断、原始自动通过、人工辅助通过及每个字段／原文改动。辅助通过不能替换原自动结果。

签收要求冻结矩阵中静默强制遗漏、新增和关系改变为零，X10／X11正确阻断，完整受支持正向用例在声明预算／配置内通过。按来源分类、用例及重复运行报告分子／分母，不叠加合成／回放重叠测试。v12基线失败仍保留为失败，即使后续部署版本通过；部署版本改变时明确只验收该版本，不能没有新版本化证据就说v12已修好。

这些门槛仅适用于有限已审核语料，不是任意计划100%准确率、交易盈利或真实安装就绪的统计证明。只有完整标注语料和评分器、没有真实供应商运行时，状态为 `REAL_ACCEPTANCE_PENDING`，不算完成验收。

## EVA-S06 — 必需产物与实施接缝

`extraction-acceptance-v1` 包含清单、不可变逐运行索引、原始响应、独立义务级评分、全部失败／复验、实际调用账与双语报告。结论绑定原文／提示／模型／配置／规则哈希及代码版本，批准或截图不能替代证据索引。录入响应重放能证明新覆盖阻断，仍须标为回放。

建议接缝：`tests/fixtures/plan_assurance/`脱敏原文／真值，聚焦离线语料／评分测试，`scripts/`有界显式真实运行入口，`docs/verification/`报告对及中立证据资产。验收对应 PMA-A01/A02、A07/A08、A12，操作继续受 PMA-D05 约束。本草案不创建这些可执行夹具／脚本或真实运行证据。
