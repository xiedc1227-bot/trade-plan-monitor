## MLP2-S05 — 数量、费用与时间语义

正式完整交易日 D，r=ATR14(D)/close(D)，使用同一合格前复权口径，沿用现有 Wilder 公式及预热契约，不另设 ATR 初值。缺失／不可比为 UNKNOWN，不当成 r=0；禁止浮点比较。

令 L 为现有官方买入数量规则与正数100股模拟数量的交集。命中倍数 v 后，Q0=max{q in L | q <= base_qty*v}。集合为空则以 VOLATILITY_BELOW_MINIMUM 阻断；这**不是**走弱最低量例外。base_qty 在任何大盘计算前由原文定义，不得为了补偿折减而提高。

将该 Q0 交给不变的 P0/P1 选择。NORMAL 使用 Q0；WEAK 取 max{q in L | q<=0.5*Q0}；其低于最低量的结果，仅在原 STRONG／S1／明确批准及0.5*Q0 < m <= Q0条件下进入 WEAK_MINIMUM。BROKEN_STRONG 仍要求 STRONG／S2及人工填写合法 Qe<=Q0。容量不足整笔阻断，P2 不自动填写 Qe。

按选出的完整候选数量计算费用；资格预览不产生执行权。例外在批准前以实际填写数量重算，执行时再算；最低佣金使每股等比缩放不成立。不能不断缩小数量直到通过门槛。

设数量q、报价买价e、目标t、风险z、每股滑点sb/ss：
- 买入支出 B=q*(e+sb)+buy_fees(q*(e+sb))。
- 目标卖出收入 T=q*(t-ss)-sell_fees(q*(t-ss))。
- 风险卖出收入 Z=q*(z-ss)-sell_fees(q*(z-ss))。
- 净收益=T-B；计划损失=B-Z；收益风险比=(T-B)/(B-Z)，仅在计划损失>0时定义。
- 双边估算成本=buy_fees+target_sell_fees+q*(sb+ss)；保本价差=该成本/q。这是场景估算，不是精确求解的未来卖价。

滑点调整价格非正或溢出须拒绝；总额用整数分，比率用精确 Decimal／有理数比较。每项独立比例收费向上取整到分，再对佣金应用约定最低值，与现有引擎一致。已含经手费不得重复加入，不静默改变旧回测核算。REQUIRED 必要输入未知或门槛不满足阻断普通买入；PREVIEW_ONLY 显示 UNKNOWN，不暗中变成门槛。不查询账户现金，不推算实际盈亏。

将交易日、来源绑定、指标／档位／base_qty／Q0、路径、申报规则及权限与信号冻结。依据／政策修正按 P0/P1 规则使受影响的待执行权限失效；等价 Decimal 格式和重新获取时间不造成失效。之后波动档位变化不修改既有数量、不生成新信号；次交易日到期和独立重置规则不变。

执行时重验数据准入、风险、容量、适用的 P1 批准、原窗口和当前费用。报价变化可使门槛失败后在原窗口内恢复，但不扩大权限。费用版本或审核目标／风险价改变使待执行权限失效，不静默替换假设。分别保留批准时与执行时预览。所有技术风险退出绕过费用检查，不因费用延迟，不新增基本面门槛。

## MLP2-S06 — 审核、持久化、API 与回放

审核界面分别展示原句、衍生字段及核验状态。P2 使用的价位记录至少两个不同证据维度，其中一个为价格结构；MA20／布林中轨算同一维度。记录来源标识、原文片段、来源日期／时间或明确未知、观察截止及人工审核决定。人工审核表达判断，不宣称两个引用自动证明价位正确。必要依据缺失阻断 P2 审核批准；不追溯要求旧已审核计划补齐新字段。

A 承载执行政策，B 承载解释及可选账户事实。提取不把 B 当政策、不把费用默认值当券商事实、不把来源语句当 P1 批准。定义缺失返回限定范围错误，保持现有阻断 A 契约；不能降成 Schema 7 删除 P2 约束。

建议 POST `/api/v1/plan-economics-previews` 为只读：请求标识审核计划／版本、规则、可用时的机会及可选拟申请 P1 数量。服务端读取权限和合格行情，调用者报价不能授权执行。响应含计划／依据哈希、computed_at、候选数量、指标／档位／Q0、估算项、门槛结果及原因。不批准、启用、模拟或创建候选。现有运行与例外预览响应展示同一政策结果；模拟通过现有事务／并发保护重新计算，不仅信任预览凭证。

沿现有信号／例外权限保存带版本的冻结政策／依据，必要时新增非破坏迁移。迁移验收只用临时数据库；不理解 Schema 8 的读取方阻断。回退保留新记录并阻断 Schema 8 启用，不改写成 Schema 7。技术哈希覆盖实际使用的输入，不含收取时间。

回放显式提供冻结费用版本、来源依据、价格、例外事件及其可用时间，不查询当前网络费用或本地批准。历史缺失阻断相应决策；未来修正／事件不能改变之前输出。真实持仓、模拟、回放账户隔离。通知区分估算与门槛，不暗示批准／成交；发送时复核并抑制失效的可操作消息。
