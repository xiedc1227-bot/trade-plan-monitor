# B1 权限候选选择：离线只读验证

## 范围

`B1` 增加单作用域原始权限预约时间读取和六作用域只读候选选择器。它未接入 RUNNING/DEGRADED 调度器，不预约或运行物理探针，不推进游标，不解除权限阻断，也不写入行情数据。持久预约回调、O/F 交替，以及阻断作用域暂缺锚点时的 30 秒本地检查，仍属于 `B2`。

## 选择契约

- 单次有界 SQLite 读取快照提供已结束且已持久化的 SSE 日历日、今天已持久化的 SSE 记录、最多十个 ACTIVE 计划，以及相关官方日线。损坏或失败的读取会向上传播。日历候选可使用最近七天内已结束的开市或休市日。其他已结束日期候选最多查看 366 天；已持久化的 `is_open=True` 具有权威性，即使日期是周末。
- `DAILY_LIMITS` 要求今天有效的旧版计划股票与已结束开市日。`DAILY_BARS` 保守使用全部持久化 ACTIVE 旧版股票（最多十个），包括单日激活已结束但 pending 或历史官方收盘仍未完成的计划。这是有界的潜在消费者集合，不表示每只股票今天都需要请求。已持久化的官方 `(S,D)` 对组成优先池，其余相关开市日对组成回退池。两池均按 `D` 倒序、`S` 升序排列，互不重叠，合计最多 3,660 对。本切片只读取优先池首对，否则读取回退池首对。只有显式规则活动计划时，这两个作用域均不产生物理候选。
- `INDEX_DAILY` 要求已认证 READY 的指数作用域和已结束的 SSE 开市日，不依赖股票计划。历史指数和实时指数候选继续遵守各自的认证、锚点和本地就绪条件。
- 候选读取不预约控制器工作，也不调用 SDK。有效到期时间是单作用域原始预约、本地延后与共享 429 冷却期三者的最大值。廉价的下一到期读取只扫描控制器和本地时间，包含当前无需求或锚点的阻断作用域，不扫描 SQLite。选择器仅选择当前到期的候选，按原始预约时间与只读轮转并列位置排序。重复窥视不推进位置。

## 验证

模拟 SDK 与临时 SQLite 测试覆盖七天及 366 天边界、周末开市记录权威性、仅显式规则计划、今天已过期的单日旧版计划分别存在持久 pending 收盘或已证明遗漏的历史收盘、O/F 过滤与 3,660 对上限、单次读取事务、读取故障传播、六作用域同到期、本地延后、共享 429 不改动原始排序，以及重复读取无 SDK 调用或预约。专项集成文件 **8 项通过**。相邻回归命令 **76 项通过**；全量 Ruff 与 `git diff --check` 通过。
