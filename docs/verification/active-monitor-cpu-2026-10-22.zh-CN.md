## AMC-V01. 决策与范围

P0 增加默认关闭、有界的诊断观测。实验中的缓冲式进程方案判定为 **P1 no-go**：输入副本合计计量为 119,382,234 字节（113.85 MiB），超过未变更的 67,108,864 字节（64 MiB）边界。没有引入生产进程、已完成证明缓存、权威检查迁移、新依赖或削弱校验。本阶段不提交/推送。

基线为 `7a7ac88`。保留前序方案/证据及无关 README 改动。AI 提取和日库存实现文件不属于本次变更。隔离实验使用冻结的只读副本，不写历史输入，也不发布结果。

## AMC-V02. 已实现的细分归因

权威观测区分健康状态、通知 SQL、配置/语义检查、进度、计划及依赖；它们仍按原同步顺序在所属事件循环执行。指数观测覆盖 SQL 迭代推进、收集、精确比对、等待、校验、数量/字节准入及回退。一个 `index.physical` 追踪标识一份物理证明；跟随者通过 `index.join` 关联，避免重复计算物理 CPU。每次读取用一个 `monitor.loop_lag` 聚合项记录最大定时器迟到，并在读取结束时取消定时器，包括取消路径。

`index.scan` 的墙钟时间包含消费阶段，但其 `activeNs` 和线程 CPU 仅计量迭代推进。`index.collect` 包含扫描；`authority.health` 包含 `authority.delivery`。不能累加嵌套区间，也不能把墙钟减线程 CPU 独占解释为 GIL 等待。1800 秒 / 1024 条追踪 / 64 个活动追踪 / 64 个区间 / 128 个已完成记录 / 1 MiB / 2 个备份的限制保持不变。仅记录白名单耗时、不透明标识、数量和字节数。

受保护的 `_read_owned`、`_assemble`、`_identities`、`_latest_index_records`、`_market_index_from_row`、准入、释放及排空函数保持基线 AST。每个请求仍独立执行前后权威、事务和时钟检查。字面规范相等、元数据绑定、全部历史证据、共享证明精确比对、时间边界、存储围栏及实际工作排空均保留。

## AMC-V03. 固定可行性结果

每种负载先执行 10 对 A/A，再执行 20 个交替 ABBA/BAAB 区组：20 个线程控制样本，加 40 个线程及 40 个进程样本。独立监控与结果/监控混合负载共完成 200 次测量。混合结果在物理校验提交后开始。权威为合成的无所有者状态；完整监控组装和完整不可变结果投影在冻结输入上执行。这些不是真实所有者或浏览器延迟测量。

| 中位数指标 | 现有线程 | 实验进程 | 变化 |
|---|---:|---:|---:|
| 独立监控完成 | 2.0121 s | 2.1943 s | +9.05% |
| 独立监控总 CPU | 2.0000 s | 2.1563 s | +7.81% |
| 混合结果启动后耗时 | 5.2224 s | 2.7358 s | -47.61% |
| 混合监控完成 | 3.0953 s | 2.8750 s | -7.12% |
| 混合批次完成 | 5.3565 s | 2.9132 s | -45.61% |
| 混合父子进程总 CPU | 5.2969 s | 5.5391 s | +4.57% |

全部完整监控输出一致，100 次混合读取的完整结果输出也一致。每次监控读取均进行 2 次独立权威检查和 1 次物理证明，随后未完成读取和保留字节归零。子进程 CPU 使用前后进程时钟差值，包含 IPC 处理，不仅是校验函数 CPU。Windows 冷启动/导入与热样本分开计量。

2008 个候选的输入计量：父进程原始保留量 30,826,621 字节；父进程序列化输入 28,864,496 字节；子进程序列化输入 28,864,496 字节；子进程重建原始保留量 30,826,621 字节。尚未计入其他 IPC 瞬时副本及 83,015 字节输出，合计已超过门槛。原始保留计数较保守，可能重复计算共用标量引用；这是已有准入计量，并非唯一存活堆字节的测量。每种方案另有 3 次全新进程观测，分别记录 Windows 工作集和私有提交量。各进程峰值之和不等于同时发生的总 RSS 峰值。

线程方案父进程工作集峰值中位数为 290.53 MiB；进程方案父进程为 345.52 MiB、子进程为 184.30 MiB，两者峰值中位数之和为 529.82 MiB。两次主要实验工作进程的冷启动为 0.9488 s 和 1.0715 s。这些测量进一步说明，未来生产方案需要先确定单独的进程绝对内存额度。

延迟门槛通过，但输入副本门槛失败。因此没有继续生产进程绝对内存额度、生产独立结果回归及 100 次真实所有者 P1 验收。流式/共享内存替代方案需要单独设计和实测生命周期约束，本次没有悄然替换。

## AMC-V04. 诊断开销

完整冻结监控读取执行 20 个交替 ABBA/BAAB 区组，关闭 40 次、开启 40 次。墙钟中位数由关闭时 2.2688 s 到开启时 2.2355 s；父进程 CPU 为 2.2344 s 和 2.2031 s。该样本通过 <=5% 墙钟 / <=2% CPU 开销门槛。观测到的负差值属于测量波动，不宣称提速。这些合成权威测量不能替代真实权威路径观测。

## AMC-V05. 真实请求与浏览器

两轮真实验证各完成 20 次独立结果及 20 次结果/监控混合尝试：120 个 HTTP 响应全部为 200，80 个完整结果响应哈希全部一致。真实输入有 2238 个候选 / 35,441,065 个保留字节；冻结可行性输入为 2008 个候选。浏览器结果标签、来源检查、刷新、实际心跳及 2/8 页并发流程均通过，没有页面/网络错误或业务写入。这些直接 HTTP 耗时与浏览器渲染检查分开报告。

| 真实结果观测 | 旧服务，诊断关闭 | P0，诊断开启 |
|---|---:|---:|
| 独立结果中位数 / 最大值 | 2.128 / 2.403 s | 2.136 / 2.685 s |
| 混合中位数 / 最大值 | 4.675 / 4.890 s | 6.010 / 6.335 s |

保留这次跨重启的混合耗时增加，不将其描述为提速或诊断开销的因果估计。它触发另行预先声明的固定同进程调查：20 个交替 ABBA/BAAB 区组，关闭 40 次、开启 40 次混合尝试，160 个 HTTP 响应全部成功，完整结果哈希一致。结果耗时由关闭时 5.7139 s 到开启时 5.8223 s（+1.90%）；批次完成为 6.1416 与 5.8395 s；进程 CPU 为 6.2734 与 6.0781 s。中位数包含所有样本。关闭样本中 9 次、开启样本中 4 次执行了第二次完整校验，因此总 CPU/批次耗时较低不是诊断的内在收益。探索性的单证明分层包含关闭 31 次、开启 36 次，也没有显示 CPU 增加。同所有者检查不能确定前述跨重启波动的全部原因。

P0 的全部 20 次混合结果请求都与实际 `http.monitor` 指数校验重叠；20 次独立结果没有这种重叠。最慢结果为第 3 轮，追踪 `e6d225252abb4062ba0c76654f7fccac`，物理结果为 `e674021fefae4cfe8faa0920d381436e`：

| 服务端 HTTP | 6.3334212 | 不可用 |
| 结果工作线程 | 6.2792696 | 2.9062500 |
| 结果发布校验，位于工作线程内 | 0.5365048 | 0.5156250 |

结果工作线程之外仅有 0.0541516 s。指数闸门等待为 0.0000009 s；观测到的最大事件循环迟到为 0.6829393 s。在后权威检查中，配置耗时 0.0847016 s、计划采集 0.1179282 s、依赖采集 0.1095891 s、通知 SQL 0.0015708 s。因此该样本的主要竞争 CPU 工作是结果审计与完整指数校验；输入扫描和事件循环调度也发生等待。没有采集独占的 GIL 等待或 GC 计数器。

20 个慢结果样本在已测量结果工作线程之外的区间最多占服务端耗时 1.01%。12 个慢监控样本在不重叠的权威/快照/激活区间之外最多为 0.53%。最慢监控追踪 `e413dd1993ed4052a5dd3cb724eae27c` 的客户端为 9.328 s、服务端为 9.3274302 s，包含两次完整快照尝试（4.8786724 s 和 3.7409956 s）。这是已有权威/身份重试路径，不代表权威变化后可以复用首轮证明。新观测不能识别具体哪一项比较发生变化。全部这些直接慢请求均满足 5% 对齐目标，没有遗漏嵌套区间或重复计算共享 CPU。

浏览器关闭后及补充调查后，未完成读取、活动调用、排队所有者、保留字节、存储暂停和连接子任务均归零，没有清除存储围栏。正常关闭完成后，已恢复同一本地服务，加载 P0 且关闭诊断（健康接口 200，无追踪响应头）。结果/准备表数量及配置哈希前后一致，包括 5 次运行、14,800 条明细和 19 个准备记录。

## AMC-V06. 验证与保留的失败

- 相关后端回归：469 通过、1 个原有平台跳过、1 个原有 Starlette 弃用警告。补强断言后，全部 9 个新增归因测试也可独立通过。
- 浏览器回归：25 通过；前端类型检查通过。
- 完整性、独立权威、断连准入和排空变异：13 项均按预期被拒绝。3 个新增观测变异也被拒绝：缺少物理追踪、缺少迭代器关闭、缺少定时器取消。
- 实验 IPC 检查：完整输出相等；未被选中的历史 JSON 损坏、载荷缺失及头部版本串线均被拒绝；取消仅移除一个观察者，跟随者仍取得实际结果；正常关闭等待子进程退出。
- 限定范围 Ruff 通过。证据保留源码指纹及受保护核心 AST 核对。

首次混合夹具尝试因冻结结果库缺少对应的不可变输入所有权目录而正确失败。保留原有 100 个独立监控观测，复制缺失目录及所有权标记并记录内容哈希后，仅执行尚未测量的混合序列，没有绕过所有权校验。首次物理追踪变异暴露测试收集依赖，现已使新增测试可独立收集。首次定时器取消变异存活，原因是测试仅检查待调度回调，遗漏已进入就绪队列的回调；现已增加实际定时器句柄断言。补充客户端首次设置请求在任何样本或诊断切换之前遭遇环境代理响应，显式直连本机后修正实验工具。全部失败均保留，没有改记为通过。
