# C1 行情源恢复：有界离线证据

## 范围与门禁

C1 在最终独立 `xhigh` 复核前保持 **OPEN**。本文汇总临时 SQLite 与模拟 SDK 边界上的 A01/A02/A04/A05 检查。`tasks/runtime-recovery-todo.zh-CN.md` 中 S3-03 核心命令 **101 项通过**；新增补充命令 **161 项通过**。`tests/unit/test_monitor_runtime.py` 中三个指定串行请求测试通过。修复后的认证生产运行时文件及相邻生产认证/实时管线回归 **72 项通过**；其测试夹具修复详见 `2026-09-25-certified-runtime-test-lifecycle.zh-CN.md`。

## A01/A02：语义与准入

`test_provider_contract.py` 验证完整兼容旧证据的原子、幂等导入，不改变源文件字节，也不把旧 READY 观察复制进语义记录。刷新时间戳不改变 `semanticRevision`，解释相关字段变化则会改变。哈希损坏、未来观察时间、端点错误、未知 profile/schema、未经验证的时间标签、不兼容的已安装 SDK、损坏的 sidecar 均安全阻断。`test_expired_observation_retains_semantics_but_not_ready_provider_health` 证明旧兼容语义仍可使用，但不会声称当前行情健康为 READY。认证生产测试现通过已安装生命周期，而非绕过数据库准入与代次所有权。

## A04：同一所有者重试

`test_production_a04_retry_timeline.py` 连续模拟四次 `trade_cal` 连接故障，第五次返回有效结果。已安装组合在 DEGRADED 时仍可本地读取，遵守 30/60/120/300 秒重试下限，保持同一所有者、控制器和运行代次，崩溃监督次数为零，恢复后由调度器提交一个精确的 10:10 目标。

## A05：持久化作用域与跨进程重启

`0023_index_permission_scopes` 迁移接收有界的旧版及混合键集合，生成独立的 `idx_mins` 和 `rt_idx_min_daily` 预约，保留其他检查点行与工作键退避，重复执行幂等，并能回滚模拟的子进程中断。无效、损坏或超限状态安全阻断。既有独立进程测试验证已观察的共享 429 冷却与权限预约在受控重启后仍保留。实时请求配置保持一个工作线程、同一时刻一条物理请求、1.25 秒节流、15 秒超时、有界队列及零次周期内重试。

`test_index_permission_process_restart.py` 在同一临时数据库上增加**两个串行 OS 进程**中的已安装组合证据，并分别验证任一端点先恢复的顺序。第一进程把一条旧 `index_minutes` 阻断升级为两个规范阻断。成功的只读探针仅清除选定作用域；另一个端点模拟权限拒绝，写入下一次 300 秒预约。随后数据库只含第二个规范权限行。第二进程恢复该行并绑定控制器及存活所有者，在到期前对该端点发出的 SDK 请求数为**零**，到期后只对仍受阻的端点发出一次有效探针。最终两个作用域均解除阻断，评估、提醒与指数快照业务写入均为零。两个端点专项测试还覆盖严格响应验证、共享 429、市场窗口优先级、物理调用起点权限依据以及失败后保留阻断。

## 边界

这些测试证明受门禁保护的离线端点可读性与持久恢复行为，不证明真实 Tushare 授权，也不代表完整 A05 或发布验收。独立复核发现仍存在 **P1 功能缺口**：`DAILY_LIMITS`、`DAILY_BARS`、`CURRENT_DAY_MINUTES`、`REALTIME_MINUTES` 和 `INDEX_DAILY` 尚无受控生产权限复核；这些 operation 的持久阻断可能一直锁存，同端点更换 token 后亦然。未请求真实行情源、发送外部通知、迁移用户数据库、推送或部署。五个作用域与最终独立复核未完成前，C1 保持 **OPEN**。
