# 大盘联动P0操作说明

[英文规范版](market-linkage-p0.md) · [规格](../specifications/monitoring/SPEC-market-linkage-p0.zh-CN.md) · [验收记录](../verification/2026-10-24-market-linkage-p0.zh-CN.md)

## MLO01 — 能力与入口

使用既有`/plans`提取、来源审核、保存、确认审核和明确启用流程。只有原文明确定义且完整的联动政策才选择Schema 6 / `condition-plan-v2`。既有Schema 5固定计划不变，不会自动转换。联动规则限定BUY/TACTICAL、`OFFICIAL_DAILY_CLOSE`、`NEXT_EXCHANGE_SESSION_ONLY`，包含完整S0、`market_policy`和`quantity_policy`，没有固定`quantity`。

| 能力 | 已实现边界 |
| --- | --- |
| 大盘状态 | 精确的已完成D；BROKEN优先于WEAK，再到NORMAL_TRANSITION；必要输入缺失为UNKNOWN |
| 相对强势 | 同一21个交易日窗口，个股前复权／指数原始点位，5/20日严格跑赢且收盘 >= MA20；仅例外资格依赖此项 |
| 确认 | 完整S0；S1增加相邻收盘／区域／不下降／成交量／RSI／风险；S2增加各自当日MA20 |
| 数量 | 显式Q0，系数`1`／`0.5`，官方单位与100股模拟单位取交集，只向下取整，容量不足整笔阻断 |
| 例外 | 两条P1例外路径均阻断；P0中任何人工操作都不能授予例外执行权限 |
| 信号 | 每个独立事件冻结整笔数量；精确的下一交易日窗口；来源修订使信号失效，不改量、不恢复 |
| 回放 | 冻结修订产生相同决策；历史范围缺失拒绝运行；保留零交易原因 |

八项展开定义均需来源绑定或独立登记的人工审核补充。仅有预设名称不足。策略参数缺失、固定／政策数量混用或联动五分钟确认会阻断完整导入／审核。运行时证据缺失则阻断依赖该证据的决策。独立提醒不增加指数或库存前提。

## MLO02 — 官方数量规则

用户于2026-10-24授权直接使用官方规则。`cn-equity-buy-grid-2026-07-06`自2026-07-06起适用于已识别普通A股代码前缀：沪深主板及创业板最小量／递增单位为100/100；科创板200/1；北交所100/1。模拟单位仍为100。因此Q0为300时，普通WEAK在主板得到100股，在科创板没有普通路径合法数量。禁止向上凑整或按容量缩量。

NORMAL_TRANSITION 下未折减的 Q0 已低于市场最小量时，由 `MARKET_QUANTITY_BELOW_MINIMUM` 阻断普通订单，不引导用户进入 WEAK／BROKEN 的 P1 例外路径。

证据记录交易所、条款、来源链接、发布／生效日期和版本。官方依据为[上交所规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)、[上交所科创板说明](https://edu.sse.com.cn/tib/qa/)、[深交所规则](https://investor.szse.cn/lawrules/rule/trade/t20260424_620190.html)和[北交所规则](https://www.bse.cn/jygl_list/200028217.html)。早于覆盖版本的日期和未识别证券前缀返回`MARKET_RULES_UNKNOWN`。此表不认证券商限额、实时供应商可用性、特殊证券状态或全部历史交易所版本。

## MLO03 — 运行与修订

既有共享指数采集器为联动指数请求60根完整日K，沿用原调度、工作线程限制及恢复机制，不新增第二个轮询器。个股准入使用既有前复权历史。板块映射包含`899050.BJ`，不代表已认证所配置供应商的北交所访问权限。

运行视图展示大盘操作数、所选路径、Q0／系数／候选量／授权量、容量、证据时间、官方单位和阻断原因。已确认信号展示冻结数量。新计算的候选量不代表新的独立交易。实际模拟在同一事务内复核整笔数量、库存修订、报价、日历、T+1、CORE及更高优先级风险。

日线OHLC／成交量／来源内容不变时，刷新时间和整批修订号变化不会使信号失效；供应商修订号是内容哈希，不是递增计数。完整采集元数据仍保留在审计证据中。指数修订一经发布，即使尚未重算，也会阻断旧的读取投影、完成证明、排队信号提醒和模拟执行。旧缓存不能覆盖已修订的当前记录。读取不采集数据、不写入业务状态。独立提醒资格单独判断。

## MLO04 — 冻结回放与存储

Schema 6研究回放使用`backtest-run-v7`，绑定指数数据集、板块身份、需求及公式哈希。连续回放存储清单携带`market-linkage-replay-source-v1`，包含完整官方指数修订及可用时间；结果拥有的副本不受可变行情数据变更影响。准入要求60个历史交易日及请求时段；每个事件只使用截至当时已可用的修订，不以当前展示用指数记录替代历史。

`market-linkage-evidence-v1`包含完整决策摘要，`market-linkage-calculation-v1`包含数量计算摘要。信号和评估JSON在既有持久记录中保留这些证据。旧数据中未出现的可选字段仍不出现，不需要新增运行时表迁移。旧版本读取器必须拒绝Schema 6，不能将其解释为固定数量；回退时应停用联动操作并保留记录。
